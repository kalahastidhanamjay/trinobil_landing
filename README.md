# trinobil_landing

Marketing landing page for **Trinobil**: billing, stock and accounts for Indian shops and restaurants.
React + Vite + TypeScript + Tailwind CSS 4.

```bash
pnpm install
pnpm dev        # http://localhost:3001
pnpm build      # production build in dist/
```

Copy `.env.example` to `.env` for production and set:
- `VITE_APP_URL` – where "Sign in / Open the web app" go
- `VITE_APK_URL` – Android app download link
- `VITE_CONTACT_EMAIL` – contact address on the page
